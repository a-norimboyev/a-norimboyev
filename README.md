## ⚙️ Ish Jarayoni & Jamoaviy Madaniyat (Workflow & Best Practices)

Har bir vazifa va loyihada sifatli kod madaniyati hamda xalqaro standartlarga rioya qilaman:

* 🎯 **Issue-Driven Development:** Har bir yangi imkoniyat yoki tuzatish uchun avval aniq Issue (vazifa) ochiladi.
* 🌿 **Git Feature Branching:** Kod hech qachon toʻgʻridan-toʻgʻri `main` tarmoqqa yozilmaydi; har bir vazifa alohida branch (`feature/*`, `fix/*`) da ishlab chiqiladi.
* 📝 **Conventional & Semantic Commits:** Har bir commit aniq va tushunarli formatda yoziladi (`feat:`, `fix:`, `refactor:`, `docs:`).
* 🔀 **Pull Requests & Code Review:** Kod asosiy tarmoqqa faqat Pull Request va sinchkov Code Review orqali qoʻshiladi.
